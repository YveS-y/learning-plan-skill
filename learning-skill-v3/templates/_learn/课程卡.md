## 🤖 AI接手协议

新会话接到「继续学习」类指令时，按以下步骤执行，不要跳步：

1. 读本文件全文，重点看「进度快照」和「关卡详情」
2. 从进度快照找到 IN_PROGRESS 关卡编号
3. 读该关卡的 Preview + Question
4. 按4步循环决定下一步：
   - 学员还没回答 → 复述该关卡的 Question
   - 学员答了一半 → 点评正确/偏差部分 + 追问
   - 学员表示「过了」→ 确认通关标准，标 ✅，进入下一关
5. 每次回复结束提醒学员更新进度快照（当前关卡 + 时间戳）
