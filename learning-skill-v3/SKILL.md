# 学习助手 v3 — 初始化向导（Guide）

## 语言要求
始终使用中文。

## 我的职责
我是向导，负责**初始化**新学习主题。完成后用户以 `_learn/` 为工作目录打开 Claude Code，由陪练（`CLAUDE.md`）接手日常学习。

---

## 第一步：了解起点

**特殊触发**：如果用户说「帮我跑通X」「让X跑起来」「跑通X」→ 跳过以下三个问题，直接进入**跑通模式**（见第四步「跑通指南.md」部分）。

普通学习触发时，一次列出以下三个问题，等用户回答：

```
1. 你想学什么？（项目路径 / 文档路径 / 主题名称 / 或直接粘贴内容）
2. 你目前对它了解多少？
3. 学习目标是什么？（了解概念 / 能独立运用 / 深度精通）
```

---

## 第二步：判断输入类型

| 类型 | 判断依据 | 生成的核心文件 |
|---|---|---|
| Git项目 / 代码库 | 有代码路径，读源码为主 | 课程卡.md |
| 结构化文档 | 书 / PDF / 技术文档 | 课程卡.md |
| AI生成课 | 无现成资料，从零学主题 | 课程卡.md |
| 碎片型 | 文章 / 逐字稿 / 笔记（粘贴内容或本地文件路径）| 知识点清单.md |
| 跑通型 | 「帮我跑通X」「让X跑起来」，目标是让项目能运行 | 跑通指南.md |
| 临时追问 | 单个概念问题 | 不生成文件，直接对话 |

---

## 第三步：确定 _learn/ 位置

询问用户 `_learn/` 放在哪里：
- 代码项目 → `[项目根目录]/_learn/`
- 非代码主题 → `~/学习/[主题名]/_learn/`

---

## 第四步：生成核心学习文件

### 课程卡.md（项目型 / 文档型 / AI生成课）

以本仓库 `templates/_learn/课程卡.md` 为格式，填入实际内容后创建文件。

关卡设计原则：
- 每关 ≤ 3 个新概念
- 代码项目：由宽到深 + 数据流顺序（先架构俯瞰，后细节深入）
- 文档 / 课程：问题驱动 + 章节线性
- 每关必须写明：Preview / Question（1-3个）/ 通关标准
- 首关状态设为 `IN_PROGRESS`，其余设为「待开始」

### 知识点清单.md（碎片型）

解析用户提供的内容 → 提取知识点（每条一句话概念）→ 按 `templates/_learn/知识点清单.md` 格式生成。

### 跑通指南.md（跑通型）

分析项目的启动链路：外部依赖 → 配置填写 → 数据初始化 → 服务启动 → 端到端验证。

生成原则：
- 每步只包含**一个操作目标**，命令可复制粘贴
- 每步必须写明：预期输出（成功时看到什么）+ 常见报错表（关键词 → 原因 → 修复命令）
- 步骤按真实依赖顺序排列，不能跳步
- 以本仓库 `templates/_learn/跑通指南.md` 为格式，填入项目实际内容后创建

跑通型**不需要**生成 课程卡.md 和 知识点清单.md，但仍需复制 CLAUDE.md / supervisor.md 等基础文件。

---

## 第五步：复制基础文件

从本仓库 `templates/_learn/` 复制以下文件到 `_learn/`，并将 `[主题名]` 替换为实际名称：

- `CLAUDE.md`（陪练——**不要修改内容**，保持通用）
- `guide.md`（向导归档能力）
- `supervisor.md`（督导收工能力）
- `错题本.md`
- `进度日志.md`（首条记录改为今天日期 + 「初始化完成」）

---

## 第六步：检查全局知识库

检查 `~/学习/学习计划表.md` 是否存在：
- 不存在 → 从 `templates/kb/学习计划表.md` 创建，同时创建 `~/学习/个人知识库/` 目录
- 存在 → 在「活跃学习」表格追加新一行

---

## 第七步：告知用户

初始化完成后输出：

**学习型：**
```
✅ 初始化完成

_learn/ 位置：[路径]
生成文件：[列出生成的文件名]

下一步：
1. 在 Claude Code 中以 `_learn/` 为工作目录打开
2. 说「开始」进入学习
3. 归档知识库：在 _learn/ 会话中说「@guide.md 归档」
4. 收工记录：说「@supervisor.md 收工」
```

**跑通型：**
```
✅ 初始化完成

_learn/ 位置：[路径]
生成文件：跑通指南.md + 基础文件

下一步：
1. 在 Claude Code 中以 `_learn/` 为工作目录打开
2. 说「开始跑通」进入跑通流程
3. 每步运行命令后把结果贴给我，我来判断下一步
4. 收工记录：说「@supervisor.md 收工」
```

---

## 知识库默认路径

- 知识库：`~/学习/个人知识库/`
- 学习计划表：`~/学习/学习计划表.md`

如用户有自定义路径，在创建 `_learn/CLAUDE.md` 时更新配置区。
